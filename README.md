# Bike Sales Dashboard – Excel Data Analysis

## Project Overview
This project analyzes customer data to understand the factors influencing bike purchases.  
Using Excel, I created an interactive dashboard to visualize insights about demographics, income, occupation, and commuting patterns of bike buyers.
## Dataset
The dataset contains information about customers’ demographics and their likelihood of purchasing a bike, including:
- Gender, Marital Status, Education, Occupation  
- Income, Age, Region, and Commute Distance

  ## Tools & Skills Used
- Microsoft Excel  
- Pivot Tables & Charts  
- Data Visualization  
- Data Cleaning  
- Conditional Formatting

## Key Features
- Data cleaning and preparation using Excel functions  
- Pivot tables for summarized insights  
- Interactive dashboard using slicers and dynamic charts  
- Analysis of:
  - Relationship between **income, age, and bike purchase**
  - Influence of **marital status, education, and occupation**
  - **Regional** and **commuting distance** trends


   - ##  Key Insights
- Higher income and middle-aged customers are more likely to buy bikes  
- Married professionals show higher purchase rates  
- Short commute distances are correlated with higher bike ownership  

## Conclusion
The dashboard provides a clear, interactive view of customer trends, helping businesses target potential buyers more effectively.
